# Victoria Vera Pacumio — Chapter XVIII invitation

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Set environment variables:
   - `PRIVATE_PAGE_PASSWORD=QUEENVICTORIA`
   - `SESSION_SECRET=` a long random secret (at least 32 random characters)
4. Run `npm start` and open `http://localhost:3000`.

The 18 Yellow Bills names are served only after the server verifies the shared password. A successful unlock creates an HTTP-only, signed, eight-hour cookie. Do not publish the password in the source code or client-side files.

## Deploy
Deploy this folder to a Node.js host that supports a persistent Express server (for example, Render or Railway). Set the two environment variables in the host dashboard. Use HTTPS. The host's public URL is the invitation link to share.
